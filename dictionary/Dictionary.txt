Dictionary:
Dictionary is a sequence datatype in which unordered items are stored as key : value pair.
it can be assumed as a mapping between a set of keys and a set of values
example :
contact list in the mobile have names and number association
dictionary itself which have word and its meaning

Key Points:
1. all the items are enclosed in curly braces {}
2. each key is separated from its value by a colon :
3. all the items (key:value pairs) are separated by comma (,)
3. each key maps to a value and this association is called key-value pair
4. keys are unique within a dictionary while values may not be 
5. Dictionary is mutable i.e. we can add new item or change the value of an existing item

immutable type can be used as keys like numbers,boolean, string, tuple

however we can use List and dictionaries as values in the dictionary

Merge two dictionaries:
Two dictionaries can be mearged into one using update() function
if same key exists in both the dictionaries the value of the key would be update 
with the new value and new kev-value pair would be added
dictionary1.update(dictionary2)

>>> dict1 = {1:'One',2:'Two'}
>>> dict2 = {3:'Three',4:'Four',5:'Five'}
>>> dict1
{1: 'One', 2: 'Two'}
>>> dict2
{3: 'Three', 4: 'Four', 5: 'Five'}
>>> dict1.update(dict2)
>>> dict1
{1: 'One', 2: 'Two', 3: 'Three', 4: 'Four', 5: 'Five'}

when same key exists in both the dictionaries:

>>> dict4 = {1:'One',2:'Two'}
>>> dict5 = {2:'Two Hundred',3:'Three',4:'Four',5:'Five'}
>>> dict4.update(dict5)
>>> dict4
{1: 'One', 2: 'Two Hundred', 3: 'Three', 4: 'Four', 5: 'Five'}

7. dict.fromkeys()

9. zip()
The zip() function returns a zip object, which is an iterator of tuples.
This zip object can be converted to List/Tuple/Dictionary as required.
The converted list/tuple object would contain List of set of Tuple objects
to create a dictionary from two lists say keys  List and values Lists
the size of dictionary would be equal to the smallest list

num = [1, 2, 3, 4, 5, 6, 7]
day = ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday']
num_day = dict(zip(num, day))
print(num_day)
{1: 'Monday', 2: 'Tuesday', 3: 'Wednesday', 4: 'Thursday', 5: 'Friday', 6: 'Saturday', 7: 'Sunday'}


# when the number of Keys and values differ then the dictionary would be formed up to the smaller list
# when the number of keys < number of values
num = [1, 2, 3, 4, 5, 6]
day = ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday']
num_day = dict(zip(num, day))
print(num_day)
{1: 'Monday', 2: 'Tuesday', 3: 'Wednesday', 4: 'Thursday', 5: 'Friday', 6: 'Saturday'}


# when the number of keys > number of values
num = [1, 2, 3, 4, 5, 6, 7]
day = ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday']
num_day = dict(zip(num, day))
