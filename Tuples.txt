Tuples:
Tuple is also a sequence datatype in python. 
elements in a tuple are stored by separating them with coma.
Generally Items of Tuple are enclosed in parentheses ()

fruits = ( 'Apple','Mango','Grapes')

however, if we assign multiple values to a variable without any brackets
 then python store it as a tuple

>>> t = 1,2,3,4
>>> t
(1, 2, 3, 4)
>>> type(t)
<class 'tuple'>

tuples are immutable. 
i.e. we can not perform Insert, update, delete operations on tuples.
Tuples are faster and more efficient than lists.
we can only add tuple to a tuple


Ex.
t = ()
t = tuple()
t1=(1,2,3,4,5,6)
>>> type(t1)
<class 'tuple'>
t2 = (1,)
>>> t2
(1,)
>>> type(t2)
<class 'tuple'>
While declaring a tuple with a single element we need to place a comma after the
first value so that it can be distinguished form parenthesized expression
A tuple having a single element is known as singleton tuple
>>> t3=(1)
>>> t3
1
>>> type (t3)
<class 'int'>
>>> t3 = ('abc')
>>> type(t3)
<class 'str'>
>>> t3 = ('abc',)
>>> type(t3)
<class 'tuple'>

t4 = (1,4.5,'Amit','#34 ABc')

Traversing a Tuple:
Tuple stores value just like list with their index number starting from 0

positive and negative indexes can be used to access the value of the tuple
positive indexes 0,1,2... negative indexes -1,-2,-3.... etc.
tuple[0] would give the first element in the tuple and
tuple[-1] would give the last element in the tuple

traversing a tuple
1. using in operator:

t1 = (1,2,3,4,5)
for i in t1:
    print(i)
	
2. using range function

t1 = (1,2,3,4,5)
l=len(t1)
for i in range(l):
    print(t1[i])

3. using enumerate function:
Enumerate function returns a tuple containing the index number/counter and the item
enumerate(iterable, start=0)
iterable can be any object that supports iteration like list, tuple, string etc.
start is optional. By default, it starts with 0. if we want to start the counter value with
some specific value then we can specify that value. but the value of the iterable would
start from the index 0 i.e. the first item in the iterable not from the start point specified
in the enumerate function.
>>> t1 = ('Amit','Dinesh','Rajesh','Vikram')
>>> t1
('Amit', 'Dinesh', 'Rajesh', 'Vikram')
>>> for i,name in enumerate(t1):
...   print(i," : ",name)
...
0  :  Amit
1  :  Dinesh
2  :  Rajesh
3  :  Vikram

using enumerate with a list
>>> l1 = ['Amit','Dinesh','Rajesh','Vikram']
>>> for i,name in enumerate(l1):
...   print(i," : ",name)
...
0  :  Amit
1  :  Dinesh
2  :  Rajesh
3  :  Vikram
>>> for i,name in enumerate(t1,2):
...   print(i," : ",name)
...
2  :  Amit
3  :  Dinesh
4  :  Rajesh
5  :  Vikram

using enumerate with a string
>>> s = "This is"
>>> for i,word in enumerate(s):
...   print(i," : ",word)
...
0  :  T
1  :  h
2  :  i
3  :  s
4  :
5  :  i
6  :  s

operations on Tuple:

1. Slicing:
tuple_name[start:stop:step]

t1 = (1,2,3,4,5,6,7,8)
t2 = t1[2:4]
t3 = t1[:4]
t5 = t1[4:]
t6 = t1[:]
t7 = t1[::2]

t1 = (1,2,3,4,5,6,7,8)

Functions in Tuple:

1. len() 
returns the length of the tuple i.e. number of elements in the tuple

len(tuple_name)

2. count()
returns the occurrence of the element in the tuple
>>>t1 = (1,2,3,1,2,1)
>>>t1.count(1)
3

3. any()
returns True or False if there is any element in the tuple or not
returns True if the tuple is not empty and False if Tuple is empty

4. min()
returns the minimum value in the tuple

5. max ()
returns maximum value in the tuple

Important: 
1. min() & max() checks on the basis of ASCII values
2. To use min() and max() all the values in the tuple should be of same type
otherwise TypeError would be displayed

>>> t1 = (1,'a',4)
>>> min(t1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: '<' not supported between instances of 'str' and 'int'
>>> max(t1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: '>' not supported between instances of 'str' and 'int'

>>> t1 = ('a','f','b')
>>> min(t1)
'a'
>>> max(t1)
'f'
>>> t1 = ('Test')
>>> max(t1)
't'
>>> min(t1)
'T'

5. sorted()
sorted() function returns a "LIST" of sorted elements.
the order of elements of the tuple are not changed as we cannot modify a tuple

>>> t1 = (41,12,32,21,2,11)
>>> a = sorted(t1)
>>> a
[2, 11, 12, 21, 32, 41]

here a is a list
>>> t1
(41, 12, 32, 21, 2, 11)

the order of elements in the tuple t1 remained unchanged

6. index()
returns the first index number of the element in the tuple if it exists in the tuple


returns the index number of the first match in the tuple 
if the searched item is not present in the tuple a ValueError is generated
tuple_name.index(value,start,stop)
start and stop are optional
if start and stop are not specified then whole tuple is searched
otherwise the specified portion is searched for the presence of the item

>>> t1 = (1,2,3,4,5,6)
>>> t1.index(2)
1
>>> t1.index(2,2,3)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ValueError: tuple.index(x): x not in tuple

We cannot use append or extend method to add elements in a tuple as tuple is immutable
We cannot use remove or pop method to remove element(s) from a tuple as tuple is immutable
we cannot sort the elements in a tuple
we cannot replace/update the element of a tuple
